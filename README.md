# 3x3-Rubic
java solve for 3x3 rubic

HOW TO RUN :
1. Download twophase.jar from https://kociemba.org/download.htm
2. This shoud be the structure of your project file :
YourProject/
>  twophase.jar
>  RubikSolverGUI.java
3. in windows :
javac -cp .;twophase.jar RubikSolverGUI.java
java  -cp .;twophase.jar RubikSolverGUI
in mac/linux :
javac -cp .:twophase.jar RubikSolverGUI.java
java  -cp .:twophase.jar RubikSolverGUI
